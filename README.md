# Curiosity Byte — channel dashboard

Live page: **https://kapilfukte.github.io/curiosity-byte-dashboard/**

- `index.html` — the dashboard (views, subscribers, every video, schedule, automation, SEO).
- `info.html` — how every Short is researched, fact-checked, made and published.
- `data/dashboard.json` — full data, pushed by the channel's bot after each run and every morning.
- `data/live.json` — newest videos' view counts, refreshed every hour by the "Live views" workflow
  from YouTube's public RSS feed (no keys).

Upcoming scripts and scheduled videos are shown as counts and times only.
